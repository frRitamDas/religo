## YouTube downloads
YouTube is enabled in the ReliGo API configuration. Availability can still depend on YouTube's current anti-bot checks and the API server's runtime environment. If a download fails, ReliGo will show the specific processing error so it can be diagnosed instead of silently changing other provider settings.
