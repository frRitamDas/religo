# Welcome to ReliGo 11.3

ReliGo has a renewed identity and a refreshed processing backend. This release brings the website and API version labels together, updates project information throughout the About section, and gives the release notes a new visual presentation.

<div class="text-backdrop">

**Website version 11.3** · **API version 11.3** · **Developer: Ritam Das**

</div>

## A renewed API and upgraded server configuration

The ReliGo API deployment has been refreshed with updated instance configuration and server-side runtime changes. The service now identifies itself as **ReliGo API 11.3**, and its server information uses the ReliGo identity.

- API package and website package versions are aligned for this release.
- API server information exposes the ReliGo service metadata used by the updated frontend.
- A short compatibility field is retained in the API response so previously opened frontend sessions are less likely to break during the rollout.
- The public processing endpoint remains at the ReliGo API address configured for this website.

## A cleaner, more consistent ReliGo identity

The About pages now identify **ReliGo** and **Ritam Das** directly, with the website version and API version clearly listed. Legacy descriptions of unrelated teams, mascot ownership, and third-party community channels have been replaced with ReliGo-specific project, source-code, and licensing information.

Historical update links are being directed to the ReliGo repository, and the release-note display has improved text hierarchy, spacing, wrapping, and image sizing for smaller screens.

## Quality-of-life improvements

- **Clearer project details:** versions, developer credit, API role, and source links are easier to find.
- **A renewed support hub:** the Community page now points to ReliGo's GitHub repository and explains how to report issues. Unrelated social buttons no longer masquerade as separate ReliGo channels.
- **Safer support links:** the old donation screen has been replaced with source-code and issue-reporting links; no payment addresses for an unrelated project are presented as ReliGo donations.
- **More useful privacy information:** the About section explains local processing, server-side processing, temporary tunnel information, and hosting-provider limitations without making a blanket zero-logs promise.
- **Improved release-note readability:** responsive title sizing, more comfortable line spacing, and better handling of long links and images.
- **A new 11.3 release banner:** custom artwork introduces the renewed API and server theme.
- **More consistent source navigation:** historical release links are routed to ReliGo's own repository wherever an equivalent destination is available.

## Server and deployment notes

The API package and website package are versioned as **11.3.0**, while the product-facing version label is **11.3**. The API deployment uses the ReliGo startup banner and a refreshed entry point; a compatibility alias is retained for older clients while static frontend deployments propagate.

## About YouTube

ReliGo's API is configured to support YouTube links, but successful retrieval can still depend on YouTube's anti-bot checks and the hosting environment. The infrastructure refresh is not a guarantee that every YouTube video will be available; unavailable or restricted videos can still fail.

## What's next

The existing logo is intentionally retained for this release. A separate branding patch will introduce replacement logo artwork, as planned.

Thanks for trying **ReliGo 11.3**.
