# Welcome to ReliGo 11.3

ReliGo 11.3 updates the project identity and aligns the website and API version labels while keeping the familiar interface, navigation, and interaction patterns.

## Renewed API and server configuration

The ReliGo API release renews the service metadata and deployment configuration and introduces updated API instances and server-side upgrades. The API and website use the public version label **11.3**.

The Render service is configured for deployment from the `main` branch. Actual instance count, concurrency, availability, and capacity depend on the active hosting configuration; the version label alone does not imply a paid-plan or capacity upgrade.

## ReliGo identity

Project details now identify **ReliGo** and **Ritam Das**. About pages, app metadata, source links, and update notes use the ReliGo identity, while license and upstream copyright notices remain preserved.

## Familiar experience, clearer details

- **Original navigation and motion:** the existing interactions and Donate page animations are retained rather than replaced with a new visual design.
- **Clearer project details:** website version, API version, developer credit, and source links remain available in About.
- **Updated project links:** source-code and issue-reporting links lead to the ReliGo repository.
- **More accurate privacy information:** About explains that processing can happen locally or on the configured API, depending on the task.
- **Compatibility retained:** the legacy `cobalt` API response field remains available for older frontend bundles during the transition. It is technical compatibility metadata, not the public product identity.

## Availability

ReliGo supports YouTube links, but successful retrieval can still depend on upstream anti-bot checks, regional restrictions, the requested media, and hosting conditions. Server configuration changes cannot guarantee every link will work.

Thanks for using **ReliGo 11.3**.
