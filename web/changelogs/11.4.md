# ReliGo 11.4 — a major ecosystem refresh

ReliGo 11.4 is a broad interface and reliability update: a more deliberate home experience, a fixed glass navigation system, a live API-powered status page, and a foundation for device-aware personalization.

<div class="text-backdrop">

</div>

## A redesigned ReliGo experience

The home page now presents the primary link workflow as the central action, with clearer hierarchy, a more expressive hero, quick-access tools, and service information. Soft gradients and restrained depth replace heavy video backgrounds so low-end phones do not need to decode decorative video just to use the app.

## Locked glass navigation

- Fixed viewport positioning with a dedicated centering property instead of using a transform for centering.
- Stronger glass blur, saturation, border highlights, and layered shadow.
- Responsive width constraints, safe-area support, and horizontal overflow containment to prevent the bar from drifting beyond the viewport.
- Bold labels and a clearer active state across desktop and mobile.

## New live status page

Visit **/status** for a live report fetched from the ReliGo API's own `/status` JSON endpoint. It reports the API process state, version, uptime, start time, configured services, and runtime metadata. The page refreshes automatically every 30 seconds and exposes the raw JSON response for diagnostics.

Status is reported by the running API process. It does not pretend to probe every upstream provider, and the page distinguishes a confirmed response from an unreachable service.

## API and runtime updates

- API status metadata is served directly from the API, not duplicated as static frontend content.
- API and website package versions move together to 11.4.0.
- The status response disables caching so the dashboard can reflect current process metadata.
- Existing processing routes, authentication, rate limits, and upstream service logic remain intact.

## Performance-minded motion and glass

- Decorative effects are CSS-driven and lightweight rather than autoplay video backgrounds.
- Reduced-motion and reduced-transparency preferences continue to be respected.
- The navigation centering approach is simplified to avoid transform-driven horizontal movement.
- Responsive layouts prioritize small screens and preserve usable touch targets.

## What comes next

The new status endpoint gives the ecosystem a stable base for more detailed diagnostics. Browser notification permission and haptic support remain opt-in and platform-dependent; browsers cannot guarantee native iOS-style haptic or notification behavior on every device.

Thanks for using **ReliGo 11.4**.
