ReliGo — это сайт, который использует отдельно размещённый API для обработки медиа. Обработка данных зависит от работающего API-инстанса и настроек хостинга, поэтому эта страница не обещает полного отсутствия журналов запросов во всех условиях.

Хостинг сайта и оператор API могут получать базовую техническую информацию, необходимую для обработки запросов, диагностики ошибок, защиты от злоупотреблений и поддержания доступности сервиса. Не отправляй личные ссылки, конфиденциальные данные или URL с токенами доступа.

<section id="saving">
<SectionHeading
    title={$t("about.heading.saving")}
    sectionId="saving"
/>

Для некоторых загрузок API должен получить, проксировать, ремуксировать или транскодировать медиа. В таких случаях API может создать временный туннель и сохранить минимальные зашифрованные данные, необходимые для выдачи результата. Стандартное время жизни туннеля в этом коде — 90 секунд, но оператор API может изменить это значение.

Временные данные туннеля могут включать исходный сервис, ссылки на медиа, сгенерированное имя файла и параметры обработки. Это не гарантирует отсутствия технических журналов на уровне всех внешних платформ и хостинг-провайдеров.
</section>
