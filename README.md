# ReliGo

ReliGo is a community-maintained media downloader based on the open-source [Cobalt project](https://github.com/imputnet/cobalt). Paste a supported public media link, choose the available options, and save the result.

**Website version:** 11.3  
**API version:** 11.3  
**Developer:** Ritam Das

- **Website:** https://religo-kappa.vercel.app
- **API:** https://religo-api.onrender.com
- **Source code:** https://github.com/frRitamDas/religo

The frontend is hosted as a static site and requires a compatible API instance for server-side processing. Configure `WEB_DEFAULT_API` to an API instance you own or are authorized to use.
